# AEM Forms BMAD Foundation

Generated projects use the same small-task operating model: every capability is
represented by a bead, linked to its implementation, integration, test, and docs
work. `bmad/foundation-config.yaml` records the feature contract selected at
generation time.

The foundation provides native AEM Forms integration points, deterministic
evaluation/HITL contracts, correlation IDs, read-only health/metrics endpoints,
and a documented resilience seam. It is a showcase foundation, not a claim that
Adobe Sign, live Inbox, or a production observability backend is configured.

# Vendor Risk Procedure

Before enabling Adobe Sign, AEM hosting, telemetry, identity, storage, or any
external provider, record the service, data classes, region, subprocessor chain,
availability commitments, security report, breach terms, deletion/return terms,
and owner. Reassess annually and after material service or data-flow changes.

Provider credentials belong in secret management. Provider webhooks require
authentication, replay protection, rate limits, and a documented failure mode.

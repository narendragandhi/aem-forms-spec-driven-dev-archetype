# Evidence Register

Keep evidence outside the source repository when it contains credentials,
personal data, production URLs, or confidential audit material. Store an
immutable reference, not sensitive content, in the bead.

| Evidence ID | Control | Period | Artifact/reference | Owner | Review date | Result |
|---|---|---|---|---|---|---|
| EVIDENCE-0001 | CC8.1 | YYYY-Q# | CI run / release | Engineering | YYYY-MM-DD | pending |
| EVIDENCE-0002 | CC6.1 | YYYY-Q# | Access export and sign-off | Platform | YYYY-MM-DD | pending |
| EVIDENCE-0003 | CC7.2 | YYYY-Q# | Alert test / incident drill | Operations | YYYY-MM-DD | pending |
| EVIDENCE-0004 | A1.2 | YYYY-Q# | Restore or failover exercise | Operations | YYYY-MM-DD | pending |

Every entry should identify who performed the control, when, what system was
covered, the result, exceptions, and the approving reviewer.

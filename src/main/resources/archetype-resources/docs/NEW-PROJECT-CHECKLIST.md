# New Project Checklist

## Before coding

- [ ] project profile and system boundary approved
- [ ] actors, data classes, and privacy requirements identified
- [ ] Author/Publish/runtime/provider prerequisites recorded
- [ ] implementation, integration, test, docs, and review beads created

## Before demo

- [ ] seeded scenario works without credentials or real personal data
- [ ] form rules and data-model behavior are visible
- [ ] evaluation and HITL approval/rejection are testable
- [ ] architecture and correlation ID are visible
- [ ] demo and live limitations are labeled

## Before production consideration

- [ ] live Author-to-Publish evidence captured
- [ ] signature and DoR evidence captured where applicable
- [ ] accessibility and security testing completed
- [ ] resilience, backup/restore, and incident exercises completed
- [ ] access, vendor, change, evidence, and privacy controls operated
- [ ] independent review scheduled; no unsupported compliance claim
